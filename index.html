🐧 Linux DevOps Commands

Complete Guide with Practical Examples & Real-World Use Cases

📋 Linux DevOps Commands Overview

What are DevOps Commands?

Essential Linux commands used by DevOps engineers for system administration, automation, monitoring, and infrastructure management. These commands are the foundation for managing servers, containers, and cloud infrastructure.

Categories Covered:

  • File & Directory Management: Navigate, create, modify, and delete files
  • System Information: Check system resources, uptime, and performance
  • User & Permissions: Manage users, groups, and file permissions
  • Network Management: Configure networking, test connectivity, manage firewalls
  • Process Management: Monitor, kill, and manage running processes
  • Log Management: View, search, and monitor log files
  • Package Management: Install, update, and manage software packages
  • Disk Management: Check disk usage, mount filesystems, manage partitions
  • Text Processing: Search, filter, and transform text data
  • Service Management: Start, stop, and manage system services

📁 File & Directory Management

pwd (Print Working Directory)
Shows the absolute path of the current directory you're in.
$ pwd
Example:
$ pwd
/home/ubuntu/projects/myapp
Use Case:
Always know where you are before running commands. Essential when navigating complex directory structures.
ls (List)
List files and directories in the current or specified directory.
$ ls [options] [directory]

Common Flags:

-lLong format (permissions, owner, size, date)
-aShow all files including hidden (starting with .)
-hHuman-readable file sizes (KB, MB, GB)
-RRecursive - list subdirectories
-tSort by modification time
Examples:
$ ls -lah /home/ubuntu
drwxr-xr-x 5 ubuntu ubuntu 4.0K Aug 18 10:30 .
-rw-r--r-- 1 ubuntu ubuntu 1.2K Aug 18 09:15 config.yaml
drwxr-xr-x 3 ubuntu ubuntu 4.0K Aug 18 08:45 scripts
$ ls -lR /etc/docker # Show all subdirectories
Use Case:
Check what files are in a directory, verify permissions, confirm if config files exist.
cd (Change Directory)
Navigate to a different directory.
$ cd [directory]
Examples:
$ cd /home/ubuntu # Go to home directory
$ cd .. # Go up one level
$ cd - # Go to previous directory
$ cd ~/projects/app # Go to ~/projects/app
Use Case:
Navigate to application directories, config folders, and log directories for deployment and troubleshooting.
mkdir (Make Directory)
Create new directories (folders).
$ mkdir [options] directory_name

Common Flags:

-pCreate parent directories if they don't exist
-mSet permissions while creating
Examples:
$ mkdir my_project
$ mkdir -p /opt/myapp/logs # Create nested directories
$ mkdir -m 755 public_dir
Use Case:
Create directories for applications, logs, backups, and configuration files during server setup.
cp (Copy)
Copy files or directories.
$ cp [options] source destination

Common Flags:

-rRecursive - copy directories and contents
-vVerbose - show files being copied
-pPreserve permissions and timestamps
Examples:
$ cp config.yaml config.yaml.bak
$ cp -r /opt/app /opt/app_backup
$ cp -v *.log /var/log/archive/
Use Case:
Backup config files before editing, copy application files during deployment.
mv (Move/Rename)
Move or rename files and directories.
$ mv [options] source destination

Common Flags:

-vVerbose - show files being moved
-fForce - overwrite without prompt
Examples:
$ mv old_name.txt new_name.txt # Rename
$ mv /tmp/app /opt/app # Move directory
$ mv *.log /var/log/archive/ # Move multiple files
Use Case:
Organize files, move logs to archive, rename backup files.
rm (Remove/Delete)
Delete files or directories. ⚠️ Be careful - deletion is permanent!
$ rm [options] file/directory

Common Flags:

-rRecursive - delete directories and contents
-fForce - don't prompt for confirmation
-iInteractive - ask before deleting each file
Examples:
$ rm old_backup.tar.gz
$ rm -rf /tmp/old_app # Delete directory
$ rm -i *.log # Ask before deleting each
Use Case:
Clean up old backups, logs, and temporary files.
touch
Create empty files or update file modification time.
$ touch filename
Examples:
$ touch config.yaml
$ touch file1 file2 file3 # Create multiple files
Use Case:
Create placeholder files for configuration, mark files as processed.
cat (Concatenate)
Display file contents, concatenate files, or create files.
$ cat [file]
Examples:
$ cat config.yaml
$ cat file1 file2 file3 > combined.txt
$ cat > newfile.txt << EOF Line 1 Line 2 EOF
Use Case:
View configuration files, combine multiple files, create files with here-documents.
less / more
View file contents one screen at a time (useful for large files).
$ less [file]
$ more [file]
Examples:
$ less /var/log/syslog
$ more large_log_file.txt
Use Case:
Read large log files without loading entire file into memory. Use 'q' to quit, Space to next page, 'G' to go to end.
find
Search for files and directories matching criteria.
$ find [path] [options] [expression]
Examples:
$ find /opt -name "*.log" # Find all log files
$ find / -type f -size +100M # Find files larger than 100MB
$ find /var/log -mtime +30 # Find files modified 30+ days ago
$ find . -name "*.bak" -delete # Delete all .bak files
Use Case:
Find old log files to delete, locate config files, find large files consuming disk space.
grep
Search for text patterns in files.
$ grep [options] pattern [file]

Common Flags:

-rRecursive - search in subdirectories
-nShow line numbers
-iCase-insensitive search
-cCount matching lines
Examples:
$ grep "ERROR" /var/log/app.log
$ grep -rn "TODO" /home/ubuntu/projects/
$ grep -c "Connection refused" /var/log/syslog
$ tail -f /var/log/app.log | grep "ERROR" # Real-time error monitoring
Use Case:
Search error logs, find configuration parameters, locate code issues.

🖥️ System Information & Monitoring

uname
Display system information (OS, kernel version, architecture).
$ uname [options]
Examples:
$ uname -a # Show all information
$ uname -r # Show kernel version
$ uname -m # Show architecture (x86_64, arm64, etc)
Use Case:
Verify OS compatibility before deploying applications, check if system is 32-bit or 64-bit.
whoami
Display current logged-in user.
$ whoami
Example:
$ whoami
ubuntu
Use Case:
Verify you're logged in as correct user before running commands.
uptime
Show how long system has been running and current load average.
$ uptime
Example:
$ uptime
14:35:22 up 45 days, 3:24, 2 users, load average: 0.52, 0.48, 0.45
Use Case:
Check if server was recently rebooted, monitor system load before deploying.
df (Disk Free)
Show disk space usage for all mounted filesystems.
$ df [options]

Common Flags:

-hHuman-readable format (KB, MB, GB)
-iShow inode usage instead of blocks
Examples:
$ df -h
Filesystem Size Used Avail Use% Mounted on
/dev/sda1 99G 45G 50G 47% /
Use Case:
Monitor disk usage, identify when disk is running full (triggers alerts at 80%+).
du (Disk Usage)
Show disk space used by files and directories.
$ du [options] [directory]

Common Flags:

-hHuman-readable format
-sShow only total for directory
-dLimit depth of directories shown
Examples:
$ du -sh /home/ubuntu # Total size of user directory
$ du -sh /var/* # Size of each item in /var
$ du -h /opt/app | sort -hr | head -20 # Find largest subdirectories
Use Case:
Find what's using disk space, identify large log directories consuming space.
free
Show RAM and swap memory usage.
$ free [options]

Common Flags:

-hHuman-readable format
Example:
$ free -h
total used free shared buff/cache available
Mem: 15Gi 8.2Gi 2.1Gi 251Mi 4.7Gi 6.3Gi
Use Case:
Monitor memory usage, identify memory leaks, decide if more RAM is needed.
top / htop
Monitor running processes, CPU, and memory in real-time.
$ top
$ htop
Examples:
$ top # Interactive process monitor
$ htop # Better version of top (more user-friendly)
$ top -p 1234 # Monitor specific process
Use Case:
Real-time monitoring of CPU-hungry processes, identify memory leaks, check system load.
ps (Process Status)
List currently running processes.
$ ps [options]
Examples:
$ ps aux # Show all processes with details
$ ps aux | grep nginx # Find nginx processes
$ ps -ef --forest # Show process tree
Use Case:
Verify applications are running, find process IDs to kill, check which user is running a process.
lscpu
Display CPU architecture information.
$ lscpu
Example:
$ lscpu | head -15
Architecture: x86_64
CPU op-mode(s): 32-bit, 64-bit
Byte Order: Little Endian
CPU(s): 8
On-line CPU(s) list: 0-7
Use Case:
Check number of CPU cores, verify CPU architecture before installing software.
systemctl status
Check status of system services.
$ systemctl status [service]
Examples:
$ systemctl status docker
$ systemctl status nginx
$ systemctl status ssh
Use Case:
Verify services are running, check startup status, diagnose service failures.

👤 User & Permissions Management

sudo (Superuser DO)
Execute commands with root/elevated privileges.
$ sudo [command]
Examples:
$ sudo apt update
$ sudo systemctl start docker
$ sudo -l # Show what commands you can run with sudo
Use Case:
Install packages, start services, modify system files as regular user.
chmod (Change Mode)
Change file and directory permissions.
$ chmod [options] mode file
Examples:
$ chmod 755 script.sh # rwx-r-x-r-x (executable script)
$ chmod 644 config.yaml # rw--r--r-- (readable config)
$ chmod +x deploy.sh # Add executable permission
$ chmod -R 755 /opt/app # Recursive - all subdirectories
Use Case:
Make scripts executable, secure config files, set proper permissions for deployment.
chown (Change Owner)
Change file and directory owner and group.
$ chown [user:group] file/directory
Examples:
$ chown ubuntu:ubuntu /home/ubuntu/app
$ chown -R nginx:nginx /var/www/html
$ chown :docker /var/run/docker.sock
Use Case:
Assign application files to correct user, fix permission issues, secure directories.
useradd
Create new user accounts.
$ sudo useradd [options] username
Examples:
$ sudo useradd -m -s /bin/bash deploy
$ sudo useradd -m -G docker jenkins
Use Case:
Create service accounts, add deployment users, manage application accounts.
groupadd
Create new user groups.
$ sudo groupadd groupname
Example:
$ sudo groupadd devops
Use Case:
Organize users into groups with specific permissions.
usermod
Modify user account properties.
$ sudo usermod [options] username
Examples:
$ sudo usermod -aG docker ubuntu # Add user to docker group
$ sudo usermod -aG sudo deploy # Add sudo privileges
$ sudo usermod -s /bin/bash jenkins # Change shell
Use Case:
Add users to groups, grant permissions, enable Docker access without sudo.
passwd
Change user password.
$ passwd [username]
Examples:
$ passwd # Change current user password
$ sudo passwd deploy # Change another user's password
Use Case:
Reset forgotten passwords, update account passwords.
id
Display user ID and group information.
$ id [username]
Example:
$ id ubuntu
uid=1000(ubuntu) gid=1000(ubuntu) groups=1000(ubuntu),4(adm),27(sudo),998(docker)
Use Case:
Verify group membership, check user permissions, troubleshoot access issues.
sudo visudo
Safely edit sudoers file to configure sudo access.
$ sudo visudo
Example (add to /etc/sudoers):
# Allow deploy user to restart nginx without password deploy ALL=(ALL) NOPASSWD: /usr/sbin/service nginx * # Allow devops group to run all commands %devops ALL=(ALL) ALL
Use Case:
Grant specific commands without password, enable automation, configure role-based access.

🌐 Network Management

ping
Test connectivity to a host by sending ICMP packets.
$ ping [options] hostname/IP
Examples:
$ ping google.com
$ ping -c 4 8.8.8.8 # Send 4 packets then stop
$ ping -i 2 server.example.com # Ping every 2 seconds
Use Case:
Test basic network connectivity, verify hostname resolution, check if server is reachable.
ifconfig / ip addr
Display network interface configuration and IP addresses.
$ ifconfig [interface]
$ ip addr show
Examples:
$ ip addr show # Show all interfaces and IPs
$ ip addr show eth0 # Show specific interface
$ ifconfig # Legacy command (still used)
Use Case:
Find server IP address, verify network configuration, check interface status.
netstat / ss
Display network connections and listening ports.
$ netstat [options]
$ ss [options]

Common Flags:

-tlnpShow listening TCP ports with process info
-aShow all connections
Examples:
$ ss -tlnp | grep 8080 # Check if port 8080 is open
$ netstat -tlnp # Show all listening ports with PIDs
$ ss -tan # Show all TCP connections
Use Case:
Verify application is listening on correct port, identify port conflicts, troubleshoot connectivity issues.
curl / wget
Download files or test HTTP endpoints.
$ curl [URL]
$ wget [URL]
Examples:
$ curl http://localhost:8080 # Test web service
$ curl -I http://example.com # Get headers only
$ curl -o file.zip http://example.com/file.zip
$ wget -O backup.tar.gz https://backup-server.com/backup.tar.gz
Use Case:
Test API endpoints, verify services are responding, download files from remote servers.
nslookup / dig
Query DNS records and resolve hostnames.
$ nslookup domain
$ dig domain
Examples:
$ nslookup google.com
$ dig example.com +short
$ dig -x 8.8.8.8 # Reverse DNS lookup
Use Case:
Troubleshoot DNS issues, verify hostname resolution, check DNS records.
traceroute
Show network path to a host, identifying each hop.
$ traceroute hostname
Example:
$ traceroute google.com
Use Case:
Diagnose routing issues, identify where connection fails, troubleshoot network latency.
firewall-cmd / ufw
Manage firewall rules and port access.
$ sudo firewall-cmd --list-ports
$ sudo ufw status
Examples:
$ sudo ufw allow 22/tcp # Allow SSH
$ sudo ufw allow 80/tcp # Allow HTTP
$ sudo firewall-cmd --list-all
Use Case:
Open ports for services, block unauthorized access, manage security rules.

⚙️ Process Management

kill
Terminate running processes by PID.
$ kill [options] PID
Examples:
$ kill 1234 # Graceful termination
$ kill -9 1234 # Force kill (SIGKILL)
$ pkill -f nginx # Kill all nginx processes
Use Case:
Stop hung processes, terminate deployment processes, force-kill runaway applications.
jobs / bg / fg
Manage background and foreground processes in shell.
$ jobs
$ command &
$ bg %1
$ fg %1
Examples:
$ long_running_task & # Run in background
$ jobs # List background jobs
$ fg %1 # Bring job 1 to foreground
Use Case:
Run multiple commands in one terminal, manage long-running tasks.
nohup (No Hangup)
Run command immune to hangups, useful for remote sessions.
$ nohup command &
Examples:
$ nohup python deploy.py > deploy.log 2>&1 &
$ nohup bash backup.sh &
Use Case:
Run long processes over SSH without losing them on disconnect.
screen / tmux
Terminal multiplexer - create persistent sessions.
$ screen
$ tmux
Examples:
$ tmux new-session -s deploy # Create named session
$ tmux attach -t deploy # Reconnect to session
$ tmux list-sessions # List all sessions
# Inside tmux: Ctrl+b+d to detach
Use Case:
Keep processes running after SSH disconnect, monitor multiple tasks simultaneously.
wait
Wait for background processes to complete.
$ wait [PID]
Example:
$ process1 & process2 & process3 & $ wait # Wait for all to complete
Use Case:
In scripts, ensure all parallel jobs complete before proceeding.

📝 Log Management

tail
Show last lines of a file, useful for live log monitoring.
$ tail [options] file

Common Flags:

-fFollow mode - show new lines as they're added (real-time)
-nNumber of lines to show
Examples:
$ tail -f /var/log/app.log # Real-time log monitoring
$ tail -n 50 /var/log/syslog # Last 50 lines
$ tail -f /var/log/app.log | grep ERROR # Monitor only errors
Use Case:
Monitor application logs during deployment, check recent errors, follow system events.
head
Show first lines of a file.
$ head [options] file
Examples:
$ head /var/log/app.log
$ head -n 20 /etc/fstab
Use Case:
Preview log file contents, check file headers without loading entire file.
wc (Word Count)
Count lines, words, or characters in files.
$ wc [options] file
Examples:
$ wc -l /var/log/app.log # Count lines
$ cat *.log | wc -l # Count lines in all logs
Use Case:
Count log entries, verify log file size, monitor log growth.
awk
Text processing language for filtering and transforming logs.
$ awk 'pattern {action}' file
Examples:
$ awk '{print $1}' /var/log/access.log # Print first column (IPs)
$ awk -F: '{print $1}' /etc/passwd # Extract usernames
$ awk '$3 > 500 {print}' data.log # Show lines where 3rd field > 500
Use Case:
Parse logs, extract specific columns, process structured data, create reports.
sed (Stream Editor)
Find and replace text in files or streams.
$ sed 's/pattern/replacement/' file
Examples:
$ sed 's/old/new/g' config.yaml # Replace all occurrences
$ sed -i 's/IP/HOSTNAME/' /etc/hosts # In-place edit
$ sed '5,10d' /etc/sudoers # Delete lines 5-10
Use Case:
Bulk edit config files, remove sensitive info from logs, transform data.
journalctl
Query systemd journal for service logs.
$ journalctl [options]
Examples:
$ journalctl -u nginx # Logs for nginx service
$ journalctl -u docker -f # Follow docker logs
$ journalctl --since "1 hour ago" # Last hour
$ journalctl -p err # Only error messages
Use Case:
Check service logs, troubleshoot service failures, monitor system events.
dmesg
Show kernel ring buffer messages.
$ dmesg [options]
Examples:
$ dmesg | tail -20 # Last 20 kernel messages
$ dmesg | grep -i error # Kernel errors
Use Case:
Debug hardware issues, check boot messages, monitor system health.

📦 Package Management

apt / apt-get
Package manager for Debian/Ubuntu systems.
$ sudo apt update
$ sudo apt install package_name
Examples:
$ sudo apt update # Update package lists
$ sudo apt upgrade # Upgrade all packages
$ sudo apt install curl wget htop # Install multiple packages
$ sudo apt remove nginx # Remove package
$ sudo apt search docker # Search for packages
Use Case:
Install/update software, manage system dependencies, update security patches.
yum / dnf
Package manager for RedHat/CentOS/Fedora systems.
$ sudo yum install package_name
$ sudo dnf install package_name
Examples:
$ sudo yum check-update # Check for updates
$ sudo yum install git docker-ce # Install packages
$ sudo yum remove nginx # Remove package
Use Case:
Install software on RedHat-based systems.
dpkg
Low-level package manager for Debian/Ubuntu (.deb files).
$ dpkg [options] file.deb
Examples:
$ dpkg -i myapp.deb # Install .deb file
$ dpkg -l | grep nginx # List installed packages
$ dpkg -r nginx # Remove package
Use Case:
Install custom .deb packages, check package details.
snap
Modern package manager with containerized apps.
$ sudo snap install package_name
Examples:
$ snap list # List installed snaps
$ sudo snap install aws-cli # Install snap package
$ sudo snap refresh aws-cli # Update snap
Use Case:
Install containerized applications, isolated dependencies.

💾 Disk Management

lsblk
List block devices and partitions.
$ lsblk
Example Output:
$ lsblk
NAME MAJ:MIN RM SIZE RO TYPE MOUNTPOINT
sda 8:0 0 100G 0 disk
└─sda1 8:1 0 100G 0 part /
Use Case:
View disk layout, identify available disks, plan partitioning.
fdisk / parted
Partition disk management tools.
$ sudo fdisk /dev/sda
$ sudo parted /dev/sda
Examples:
$ sudo parted -l # List all disks and partitions
$ sudo parted /dev/sdb mkpart primary 0 100G
Use Case:
Create partitions, resize disks, manage disk layout.
mkfs (Make FileSystem)
Create filesystems on partitions.
$ sudo mkfs -t ext4 /dev/sda1
Examples:
$ sudo mkfs.ext4 /dev/sdb1 # Create ext4 filesystem
$ sudo mkfs.xfs /dev/sdb1 # Create XFS filesystem
Use Case:
Format new disks, initialize storage devices.
mount / umount
Mount and unmount filesystems.
$ sudo mount /dev/sdb1 /mnt/data
$ sudo umount /mnt/data
Examples:
$ mount # List mounted filesystems
$ sudo mount /dev/sdb1 /data # Mount device
$ sudo umount /mnt/data # Unmount filesystem
Use Case:
Mount data drives, attach external storage, manage NFS shares.
rsync
Fast, incremental file sync (great for backups).
$ rsync -avz source destination
Examples:
$ rsync -avz /opt/app /backup/ # Local backup
$ rsync -avz /data/ user@server:/backup/data/ # Remote backup
$ rsync -avz --delete /source/ /dest/ # Mirror directories
Use Case:
Create backups, sync files between servers, incremental updates.
tar (Tape Archive)
Create and extract compressed archives.
$ tar [options] file.tar.gz

Common Flags:

-cCreate archive
-vVerbose - show files
-zGzip compression
-xExtract archive
-fFile to operate on
Examples:
$ tar -cvzf backup.tar.gz /opt/app # Create gzipped archive
$ tar -xvzf backup.tar.gz # Extract archive
$ tar -tvzf backup.tar.gz # List contents
Use Case:
Create backups, compress application files, distribute packages.
zip / unzip
Create and extract ZIP archives.
$ zip -r file.zip directory
$ unzip file.zip
Examples:
$ zip -r app.zip /opt/app/ # Create zip archive
$ unzip app.zip # Extract zip
$ unzip -l app.zip # List contents
Use Case:
Share files, create Windows-compatible archives.

✏️ Text Processing

sort
Sort lines of text files.
$ sort [options] file
Examples:
$ sort /etc/passwd # Sort alphabetically
$ sort -n file.txt # Numeric sort
$ sort -r file.txt # Reverse sort
Use Case:
Organize data, prepare files for comparison.
uniq
Remove duplicate lines from sorted file.
$ uniq [options] file
Examples:
$ sort file.txt | uniq # Remove duplicates
$ uniq -c file.txt # Count occurrences
Use Case:
Remove duplicate logs, analyze frequencies.
cut
Extract columns from files.
$ cut -d: -f1 /etc/passwd
Examples:
$ cut -d: -f1 /etc/passwd # Get usernames
$ cut -d' ' -f1,2 access.log # Get IP and username
Use Case:
Extract specific columns from CSV/structured data.
tr (Translate)
Translate or delete characters.
$ tr [options] set1 set2
Examples:
$ echo "hello" | tr 'a-z' 'A-Z' # Convert to uppercase
$ tr -d '\r' < file.txt > clean.txt # Remove carriage returns
Use Case:
Convert case, remove characters, format data.
paste
Merge lines from multiple files side by side.
$ paste file1 file2
Example:
$ paste <(seq 1 5) <(seq 100 105)
1 100
2 101
3 102
Use Case:
Combine related data files, correlate logs.
comm
Compare two sorted files line by line.
$ comm file1 file2
Example:
$ comm old_list.txt new_list.txt # Show differences
Use Case:
Find new/removed items, compare versions.

🔧 Service Management

systemctl
Manage systemd services and system state.
$ sudo systemctl [command] service_name
Examples:
$ sudo systemctl start nginx # Start service
$ sudo systemctl stop nginx # Stop service
$ sudo systemctl restart nginx # Restart service
$ sudo systemctl enable nginx # Enable at boot
$ sudo systemctl status nginx # Check status
Use Case:
Manage application services, enable auto-startup, troubleshoot service issues.
service
Legacy service management (works on older systems).
$ sudo service service_name [start|stop|restart]
Examples:
$ sudo service nginx start
$ sudo service docker restart
Use Case:
Works on older systems without systemd.
chkconfig
Configure services to start at boot (RedHat systems).
$ sudo chkconfig [service] on/off
Examples:
$ sudo chkconfig nginx on # Enable at boot
$ chkconfig --list # List services
Use Case:
Manage startup scripts on RedHat/CentOS.
crontab
Schedule recurring tasks and jobs.
$ crontab -e
Example Crontab Entry:
# Run backup daily at 2 AM 0 2 * * * /opt/scripts/backup.sh # Run cleanup every Sunday at 3 AM 0 3 * * 0 /opt/scripts/cleanup.sh # Run every 5 minutes */5 * * * * /opt/scripts/monitor.sh
Use Case:
Schedule backups, log rotation, monitoring tasks, cleanup jobs.
at
Schedule one-time jobs to run at specific time.
$ at [time]
Example:
$ at 3:30 PM tomorrow at> /opt/scripts/deploy.sh at> Ctrl+D (to save)
Use Case:
Schedule one-time deployments, maintenance tasks at off-peak hours.
